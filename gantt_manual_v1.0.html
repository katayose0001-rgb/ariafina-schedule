📋1. 概要

このツールはARIAFINAプロジェクトのスケジュール管理用ガントチャートです。ブラウザで動作し、インターネット経由で複数人が閲覧・編集できます。

主な機能

機能説明
ガントチャート表示年間スケジュールをバー形式で可視化。土日・祝日を自動色分け
WBS 4階層管理プロジェクト→サブ成果物→ワークパッケージ→補助ワークの4段階
マイルストーン開始日と終了日が同じタスクを◆アイコンで表示
依存関係先行タスクを設定し、終了日変更時に自動連動
編集ロックFirebase連携による複数人編集ロック機能
UNDOタスク追加・削除・編集を最大20件まで取り消し可能
CSV出力Excelで開けるCSVファイルを出力

🔒4. 編集ロック機能

Firebase Realtime Databaseを使い、複数人が同時に編集しないようロック管理を行います。

編集を開始するには

1
ツールバー左端の入力欄に自分の名前を入力してEnterで保存（次回以降は自動入力）
2
編集開始 ボタンをクリック
3
表示が ✏️ 片寄（編集中） に変わり編集可能になります

編集を終了するには

編集終了 ボタンをクリックするとロックが解放されます。

ロック状態の見方

表示状態できること
編集可能 誰も編集していない 「編集開始」をクリックして編集を開始
✏️ 自分（編集中） 自分が編集中 全機能が使用可能
🔒 ○○が編集中 他の人が編集中 閲覧のみ（編集不可）
⚠️ 注意：「強制解放」ボタンは緊急時のみ使用してください。相手が編集中の場合、データが失われる可能性があります。
💡 自動解放：ブラウザを閉じる・タブを閉じる・ネット切断時は自動的にロックが解放されます。

📝5. タスク管理

タスクの追加

1
ツールバーの ＋ タスク追加 をクリック
2
右側パネルに入力フォームが表示されます
3
タスク名（必須）・親タスク・挿入位置・担当者・日数・開始日・表示色・先行タスクを設定
4
追加 をクリック
💡 親タスクを指定するとサブタスクとして追加され、WBSが自動的に採番されます。

サブタスクの追加（右クリックメニュー）

タスク名を右クリックするとメニューが表示されます。

メニュー項目動作
✏️ タスクを編集右パネルで編集画面を開く
➕ サブタスクを追加 Lv○そのタスクの子として追加パネルを開く
🗑️ 削除タスクと子孫をすべて削除

タスクの編集

以下のいずれかの操作で編集パネルを開きます：

操作動作
タスク名をダブルクリック編集パネルを開き、開始日列へ自動スクロール
WBS番号をダブルクリック編集パネルを開き、開始日列へ自動スクロール
ガントバーをクリック編集パネルを開く
タスク名を右クリック→「タスクを編集」編集パネルを開く
💡 編集パネルの項目：タスク名（太字）・WBS（自動）・担当者・日数・開始日・終了日・表示色・レベル・親タスク・位置の移動・先行タスク

タスクの削除

編集パネル下部の 削除 ボタンをクリック。

⚠️ 注意：親タスクを削除すると子孫タスクもすべて削除されます。削除後はUNDOで復元できます。

タスクの移動（上下）

編集パネルの「位置の移動」で ▲ 上へ ▼ 下へ をクリックすると、同じ親を持つ兄弟タスクの中で順序を入れ替えられます。子孫タスクも一緒に移動します。

🗂️6. WBS構造（4階層）

タスクは4段階の階層で管理されます。WBS番号は自動採番されます。

レベルWBS例意味行の色
Lv11プロジェクト成果物青ボーダー・太字
Lv21.1主要サブ成果物緑ボーダー・薄灰
Lv31.1.1ワークパッケージ橙ボーダー
Lv41.1.1.1補助ワーク赤ボーダー
📌 折りたたみ：タスク名左の ▼ ボタンをクリックすると子孫タスクを非表示にできます。もう一度クリックで展開します。

挿入位置の指定

タスク追加時に「挿入位置」で「〇〇の前に挿入」を選ぶと、指定したタスクの直前に追加できます。WBSは自動的に繰り下がります。

📊7. ガントチャート操作

ガントバーの操作

操作動作
バーをクリックタスク編集パネルを開く
バー左端をドラッグ開始日を変更（日数は自動再計算）
バー右端をドラッグ終了日を変更（日数は自動再計算）

日付の設定

方法説明
開始日ボタンをクリックカレンダーポップアップで日付を選択
開始日を変更日数をもとに終了日が自動計算
終了日を変更日数が逆算されて更新
💡 実働日数：土日・祝日を除いた実働日数でカウントします。カレンダーポップアップで「実働日のみ」モードに切り替えも可能です。

タスク名列の幅変更

ヘッダーの「タスク名」列の右端にカーソルを当てると ↔ カーソルに変わります。ドラッグして幅を自由に調整できます（設定は自動保存）。

今日の位置へ移動

ツールバーの ▶ 今日 ボタンをクリックすると今日の列へスクロールします。起動時も自動的に今日へジャンプします。

◆8. マイルストーン

開始日と終了日が同じ日付のタスクは自動的にマイルストーンとして表示されます。

項目説明
表示形式◆（ひし形）アイコン＋タスク名をガント上に表示
色タスクの表示色を引き継ぎ
作成方法タスク編集で開始日と終了日に同じ日付を設定するだけ
フィルターツールバーの「◆ マイルストーンのみ」トグルでマイルストーンだけ表示
📌 マイルストーンのみ表示：ツールバーのトグルをONにすると、マイルストーン（開始日＝終了日）のタスクのみが表示されます。OFFで全タスク表示に戻ります。

⇢10. 依存関係

タスクに「先行タスク」を設定すると、先行タスクの終了翌営業日が開始日として連動します。

設定方法

1
タスク編集パネルを開く
2
「先行タスク（依存）」のドロップダウンから先行タスクを選択
3
「保存」をクリック（または「依存適用」ボタンで開始日を即時補正）
機能説明
自動連動先行タスクの終了日が変わると後続タスクの開始日が翌営業日に自動移動
連鎖伝播A→B→Cのように複数段階の依存も自動更新
循環検知A→BかつB→Aのような循環依存は自動的に防止
矢印表示ガント上に紫の破線矢印で依存関係を可視化
表示切替ツールバーの「⇢ 依存関係を表示/非表示」で切り替え

↩11. UNDO機能

画面下部のUNDOバーは常時表示されています。

対応操作説明
タスク追加追加を取り消してタスクを削除
タスク削除削除を取り消してタスクを復元
タスク編集・保存保存前の状態に戻す
担当者管理の更新変更前の担当者リストに戻す
全タスク削除全削除を取り消して全タスクを復元
📌 最大20件：操作履歴は最大20件まで保持されます。「↩ 元に戻す」を繰り返し押すことで複数回遡れます。

🚀13. ファイル更新時のGitHubへの反映

ファイルを修正した場合、以下のコマンドでGitHubに反映できます。

手順

1
デスクトップの ariafina_schedule フォルダ内でコマンドプロンプトを開く（アドレスバーに cmd と入力）
2
以下を順番に実行：
git add annual_gantt_schedule_github_v2.html
git commit -m "更新内容のメモ"
git push
3
1〜2分後にGitHub Pagesに反映されます
💡 確認：反映後は Ctrl+Shift+R（強制リロード）でキャッシュをクリアして最新版を確認してください。
