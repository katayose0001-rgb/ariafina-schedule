✏️Editing Basics — Lock & Save

⚠️ Always press "Start Editing" before making any changes. All operations are blocked until you acquire the edit lock.
1

Enter Your Name

Type your name in the input field on the top-left (e.g. Katayose, Ishikawa). This lets other users see who is currently editing.

2

Press Start Editing

This acquires the edit lock. Other PCs will show "[Name] is editing" and all operations will be blocked for them.

3

Make Your Changes

Add, edit, or delete tasks. Changes appear on screen immediately.

4

Press End Editing

Data is saved to Firebase and the lock is released. Other PCs automatically receive the updated data within seconds.

💡 If you close the browser without pressing "End Editing", the lock is released automatically.

Milestones

Check ◆ Milestone (1 day) in the edit panel to display the task as a diamond ◆ icon. To revert to a normal Gantt bar, uncheck the option — the task will reset to a 3-day bar automatically.

Dependencies (Predecessor Tasks)

Set a predecessor in the edit panel to automatically link the start date to the next business day after the predecessor ends. Toggle arrow visualization with the ⇢ Show Dependencies button.

🌐English Translation

English translations appear automatically below Japanese task names. Great for sharing schedules with the Elica team.

Translation Priority

  • 1
    Manual English Title (fixed, highest priority)
    Value typed directly into the "English Title" field in the edit panel
  • 2
    User Dictionary (Firebase-shared across all PCs)
    Automatically learns from past translations. Shared with the whole team.
  • 3
    Built-in Dictionary (60+ ARIAFINA terms)
    Pre-loaded with business terminology for ARIAFINA / Fujioh / Elica workflows
  • 4
    Claude AI Translation (requires API key)
    AI translates unknown terms. Results are automatically added to the user dictionary.

How to Translate

ActionHow To
Translate one taskOpen edit panel → click Auto Translate
Translate all tasks at oncePress 🌐 Bulk Translate in the toolbar (after pressing Start Editing)
Enter manuallyEdit panel → "English Title (optional)" field → type → Save
Set API keyPress 🔑 API Key in the toolbar
💡 Once a task name is translated, it is saved to the shared user dictionary. Future sessions display it instantly — even without an API key.
⚠️ Claude API is a paid service (~$0.000005 per task). API keys are obtained at console.anthropic.com. The built-in and user dictionaries handle most common terms for free.

🔒Real-time Sync & Edit Lock

Lock Status

Connecting… — Waiting for Firebase connection
Editable — No one is currently editing. Click "Start Editing" to begin.
[Your name] (editing) — You hold the lock. All edits are live.
[Name] is editing — Someone else holds the lock. All your operations are blocked.
If another user's lock is stuck, press Force Unlock to release it. Note: unsaved changes by the other user may be lost.
💡 Data is saved automatically when you press "End Editing". Closing the browser also releases the lock automatically.

📥CSV Import

Bulk-import tasks from an Excel CSV file. Ideal for migrating an existing schedule into the Gantt chart.

Steps

1

Press "Start Editing"

Import requires the edit lock.

2

Click 📥 Import CSV

The import modal opens.

3

Drop or select your CSV file

Drag & drop, or click to browse. UTF-8 and Shift-JIS are both supported.

4

Choose import mode

Append — adds to existing tasks. Replace — deletes all existing tasks first (export a backup first!).

5

Click "Execute Import"

Tasks are created, WBS numbers are renumbered, and the view updates automatically.

CSV Format

ColumnContentRequired
AWBS number (e.g. 1.4.1)Optional
BTask name✅ Required
CAssignee nameOptional
DDuration (days)Optional (default: 1)
EStart date (YYYY-MM-DD)Optional
FEnd date (YYYY-MM-DD)Optional
💡 Click the Template button in the import modal to download a sample CSV with the correct format.
WBS hierarchy (parent–child relationships) is inferred automatically from the dot-separated WBS numbers (e.g. 1.4 is the parent of 1.4.1).

❓FAQ

Q English translations are not showing
Press 🌐 Bulk Translate in the toolbar. For terms not in the dictionary, an API key is needed. Without an API key, manually enter the English title in the edit panel — it will be saved to the shared user dictionary and displayed automatically from then on.
Q Data is missing or not loading
Firebase may still be connecting. Wait a few seconds and reload. Data is fully loaded once the status shows Editable (green dot).
Q I cannot edit — operations are blocked
Check whether "[Name] is editing" is displayed (red dot). Ask that person to press "End Editing". In urgent cases, use the Force Unlock button.
Q WBS numbers look wrong after editing
WBS numbers are renumbered automatically after every add, delete, or move operation. Manual editing of WBS numbers is not supported by design.
Q I accidentally deleted a task
Click ↩ Undo at the bottom of the screen to reverse up to 20 actions. Recovery is possible as long as you have not pressed "End Editing" yet.
Q A milestone is showing as a diamond but should be a bar
Open the edit panel and uncheck ◆ Milestone (1 day). The task will automatically reset to a 3-day Gantt bar. Adjust the duration as needed, then press Save.
Q Is the Claude API free?
No — it is a separate paid service from Anthropic. Claude.ai Pro plans do not include API access. The cost is extremely low (~$0.000005 per translation). A $5 deposit covers thousands of tasks. Get your key at console.anthropic.com.
